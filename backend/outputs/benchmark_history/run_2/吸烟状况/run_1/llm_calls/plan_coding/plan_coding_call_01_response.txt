## 规划思路

### 1. 数据预处理（preprocess）
- **丢弃 id 列**：`id` 列有 12000 个唯一值，是典型的主键列，必须丢弃。
- **清洗列名**：将包含特殊字符 `(`, `)`, `空格` 的列名替换为纯字母数字下划线，确保 LightGBM/XGBoost 兼容。
- **目标列保留**：`mode='test'` 时保留 `smoking` 列（虽然 test.csv 没有目标列，但系统框架要求保留）。
- **缺失值处理**：数据画像显示无缺失值，但保留 `SimpleImputer` 作为安全兜底。
- **数值缩放**：对数值特征使用 `StandardScaler` 标准化，在 `mode='train'` 时拟合，`mode='test'` 时应用。
- **类别编码**：所有特征均为数值类型，无需类别编码。

### 2. 特征工程（feature_engineering）
- **丢弃目标列**：移除 `smoking` 列，返回纯特征矩阵。
- **创建新特征**：
  - BMI 指数：`weight(kg) / (height(m))^2`
  - 血压差：`systolic - relaxation`
  - 血脂比值：`triglyceride / HDL`（与吸烟相关的生物标志物）
  - 肝功比值：`AST / ALT`（De Ritis 比值，与吸烟相关）
- **特征选择**：保留所有特征，树模型会自动做特征选择。

### 3. 模型构建（build_model）
- **模型选择**：LightGBM（LGBMClassifier），对数值型数据效果好，训练速度快。
- **超参数设置**：
  - `objective='binary'`，二分类
  - `scale_pos_weight`：根据类别不平衡比例（0.3655 / 0.6345 ≈ 1.74）设置
  - `max_depth=6`，防止过拟合
  - `num_leaves=31`，与 max_depth 匹配
  - `learning_rate=0.05`，较小的学习率
  - `n_estimators=500`，配合早停
  - `subsample=0.8`，行采样
  - `min_child_samples=20`，防止过拟合
- **早停回调**：使用 `lgb.early_stopping(stopping_rounds=50)`

### 4. 评估指标
- 使用系统默认的 ROC-AUC 评估指标，无需自定义 `evaluate_model`。

import re
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer
from lightgbm import LGBMClassifier
import lightgbm as lgb

# 全局状态变量
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 1. 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 2. 清洗列名：将特殊字符替换为下划线
    df.columns = [re.sub(r'[^\w]', '_', str(c)) for c in df.columns]
    
    # 3. 分离特征和目标列
    target_col = 'smoking'
    # 注意：test.csv 没有目标列，所以需要检查
    if target_col in df.columns:
        y = df[target_col]
        X = df.drop(columns=[target_col])
    else:
        y = None
        X = df
    
    # 4. 数值特征列（所有特征都是数值类型）
    numeric_cols = X.columns.tolist()
    
    # 5. 标准化
    if mode == 'train':
        # 拟合 scaler
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        PREPROCESS_STATE['scaler'] = scaler
        PREPROCESS_STATE['numeric_cols'] = numeric_cols
    else:  # mode == 'test'
        # 应用已拟合的 scaler
        scaler = PREPROCESS_STATE['scaler']
        X_scaled = scaler.transform(X)
    
    # 6. 转换回 DataFrame
    X_processed = pd.DataFrame(X_scaled, columns=numeric_cols)
    
    # 7. 重新添加目标列（如果存在）
    if y is not None:
        X_processed[target_col] = y.values
    
    return X_processed


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 丢弃目标列
    target_col = 'smoking'
    if target_col in df.columns:
        df = df.drop(columns=[target_col])
    
    # 创建新特征
    # BMI = weight(kg) / (height(m))^2
    if 'height_cm_' in df.columns and 'weight_kg_' in df.columns:
        df['bmi'] = df['weight_kg_'] / ((df['height_cm_'] / 100) ** 2)
    
    # 血压差
    if 'systolic' in df.columns and 'relaxation' in df.columns:
        df['blood_pressure_diff'] = df['systolic'] - df['relaxation']
    
    # 血脂比值（triglyceride / HDL）
    if 'triglyceride' in df.columns and 'HDL' in df.columns:
        df['tg_hdl_ratio'] = df['triglyceride'] / (df['HDL'] + 1e-6)
    
    # 肝功比值（AST / ALT）
    if 'AST' in df.columns and 'ALT' in df.columns:
        df['ast_alt_ratio'] = df['AST'] / (df['ALT'] + 1e-6)
    
    # 确保所有列都是数值类型
    for col in df.columns:
        if df[col].dtype == 'object':
            df[col] = pd.to_numeric(df[col], errors='coerce')
    
    # 填充可能产生的 NaN（除零保护）
    df = df.fillna(0)
    
    return df


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    # 类别不平衡比例
    # 训练集中 smoking=1 的比例约为 0.3655，smoking=0 的比例约为 0.6345
    # scale_pos_weight = count(0) / count(1) ≈ 0.6345 / 0.3655 ≈ 1.74
    scale_pos_weight = 0.6345 / 0.3655
    
    model = LGBMClassifier(
        objective='binary',
        scale_pos_weight=scale_pos_weight,
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        min_child_samples=20,
        random_state=42,
        verbosity=-1
    )
    
    return model
