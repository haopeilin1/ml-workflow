## 规划

### 1. 数据理解
- **任务**: 回归预测，目标列 `SSPL`（缩放声压级）
- **特征**: `f`（频率）, `alpha`（攻角）, `c`（弦长）, `U_infinity`（来流速度）, `delta`（吸力面位移厚度）
- **数据量**: 1202 条训练数据
- **数据质量**: 所有列无缺失值，均为数值类型
- **ID列**: `id` 列有 1202 个唯一值（与行数相同），必须丢弃

### 2. 预处理策略 (`preprocess`)
- **丢弃ID列**: 无条件丢弃 `id` 列
- **目标列保留**: 在 `mode='test'` 时，保留 `SSPL` 列（如果存在）
- **数值缩放**: 所有特征均为数值类型，使用 `StandardScaler` 进行标准化
- **状态管理**: 在 `mode='train'` 时拟合 `StandardScaler`，保存到 `PREPROCESS_STATE`；`mode='test'` 时应用已拟合的 scaler

### 3. 特征工程策略 (`feature_engineering`)
- 所有特征均为数值类型，无需编码
- 创建交叉特征：`f * delta`（频率与位移厚度交互），`alpha * U_infinity`（攻角与速度交互）
- 创建多项式特征：`f^2`, `delta^2`（捕捉非线性关系）
- 创建比值特征：`U_infinity / c`（速度与弦长比）
- 分离目标列 `SSPL`，返回纯特征矩阵

### 4. 模型策略 (`build_model`)
- 使用 `LightGBM` 回归模型（`LGBMRegressor`）
- 设置正则化参数防止过拟合：
  - `max_depth=6`
  - `num_leaves=31`
  - `subsample=0.8`
  - `min_child_samples=20`
  - `learning_rate=0.05`
  - `n_estimators=500`
- 使用早停（`callbacks=[lgb.early_stopping(stopping_rounds=50)]`）

### 5. 自定义评估指标 (`evaluate_model`)
- 计算 RMSE（均方根误差）作为主要评估指标
- 同时计算 MAE 和 R² 作为辅助指标

import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
from lightgbm import LGBMRegressor
import lightgbm as lgb

# 全局状态存储
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    global PREPROCESS_STATE
    
    # 复制数据避免修改原始数据
    df = df.copy()
    
    # 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 分离特征列和目标列
    feature_cols = ['f', 'alpha', 'c', 'U_infinity', 'delta']
    target_col = 'SSPL'
    
    # 确保特征列都存在
    available_features = [col for col in feature_cols if col in df.columns]
    
    if mode == 'train':
        # 拟合 StandardScaler
        scaler = StandardScaler()
        scaler.fit(df[available_features])
        PREPROCESS_STATE['scaler'] = scaler
    else:
        # 应用已拟合的 scaler
        scaler = PREPROCESS_STATE.get('scaler')
        if scaler is None:
            raise ValueError("PREPROCESS_STATE 中未找到 scaler，请先运行 mode='train'")
    
    # 应用标准化
    df[available_features] = scaler.transform(df[available_features])
    
    return df

def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    # 复制数据
    df = df.copy()
    
    # 特征列列表
    feature_cols = ['f', 'alpha', 'c', 'U_infinity', 'delta']
    target_col = 'SSPL'
    
    # 确保特征列都存在
    available_features = [col for col in feature_cols if col in df.columns]
    
    # 创建交叉特征
    df['f_delta'] = df['f'] * df['delta']
    df['alpha_U_infinity'] = df['alpha'] * df['U_infinity']
    
    # 创建多项式特征
    df['f_squared'] = df['f'] ** 2
    df['delta_squared'] = df['delta'] ** 2
    
    # 创建比值特征
    df['U_infinity_over_c'] = df['U_infinity'] / (df['c'] + 1e-8)  # 避免除零
    
    # 选择所有特征列（包括新创建的）
    all_feature_cols = available_features + ['f_delta', 'alpha_U_infinity', 'f_squared', 'delta_squared', 'U_infinity_over_c']
    
    # 分离目标列
    if target_col in df.columns:
        X = df[all_feature_cols]
    else:
        X = df[all_feature_cols]
    
    return X

def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    model = LGBMRegressor(
        objective='regression',
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        min_child_samples=20,
        random_state=42,
        verbose=-1  # 抑制训练日志
    )
    
    return model

def evaluate_model(model, X_val, y_val):
    """
    自定义验证集评估指标。
    返回一个 dict，键名以 val_ 开头。
    """
    val_preds = model.predict(X_val)
    
    rmse = float(np.sqrt(mean_squared_error(y_val, val_preds)))
    mae = float(mean_absolute_error(y_val, val_preds))
    r2 = float(r2_score(y_val, val_preds))
    
    return {
        'val_rmse': rmse,
        'val_mae': mae,
        'val_r2': r2
    }
