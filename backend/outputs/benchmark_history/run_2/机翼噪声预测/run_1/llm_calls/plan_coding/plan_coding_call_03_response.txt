### 优化策略

#### 1. 超参数调优
- 使用 **Optuna** 进行超参数搜索，搜索空间：
  - `num_leaves`: 15-50
  - `learning_rate`: 0.01-0.1
  - `min_child_samples`: 5-30
  - `subsample`: 0.6-0.9
  - `feature_fraction`: 0.6-0.9
  - `reg_alpha`: 0.0-1.0
  - `reg_lambda`: 0.0-1.0
- 使用 **TPE** 采样器，优化目标为验证集 RMSE
- 设置早停防止过拟合

#### 2. 特征工程增强
- 保留现有交叉特征（f_delta, alpha_U_infinity 等）
- 新增物理意义特征：
  - **Strouhal 数相关**: `f * c / U_infinity`（无量纲频率）
  - **雷诺数相关**: `U_infinity * c`（与雷诺数成正比）
  - **攻角与弦长交互**: `alpha * c`
  - **速度平方**: `U_infinity^2`（动压相关）
- 使用 **SelectKBest** 或 **RFECV** 进行特征选择，避免维度灾难

#### 3. 模型集成（Bagging）
- 使用 **BaggingRegressor** 包装 LightGBM，设置 `n_estimators=10`，`max_samples=0.8`
- 每个基模型使用不同的随机种子，增加多样性
- 集成后预测方差降低，泛化能力提升

#### 4. 过拟合控制
- 严格限制 `max_depth=6`（当前为8，偏大）
- 增加 `min_child_samples=20`（当前合理）
- 使用 `reg_alpha` 和 `reg_lambda` 正则化
- 使用早停（`early_stopping_rounds=50`）

### 代码修改要点

- 特征选择使用训练集统计量，transform 验证集和测试集

from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score

PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    global PREPROCESS_STATE
    
    # 复制数据避免修改原始数据
    df = df.copy()
    
    # 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 分离特征列和目标列
    feature_cols = ['f', 'alpha', 'c', 'U_infinity', 'delta']
    target_col = 'SSPL'
    
    # 确保特征列都存在
    available_features = [col for col in feature_cols if col in df.columns]
    
    if mode == 'train':
        # 拟合 StandardScaler
        scaler = StandardScaler()
        scaler.fit(df[available_features])
        PREPROCESS_STATE['scaler'] = scaler
    else:
        # 应用已拟合的 scaler
        scaler = PREPROCESS_STATE.get('scaler')
        if scaler is None:
            raise ValueError("PREPROCESS_STATE 中未找到 scaler，请先运行 mode='train'")
    
    # 应用标准化
    df[available_features] = scaler.transform(df[available_features])
    
    return df

    特征工程。

    """
    # 复制数据

    df['alpha_delta'] = df['alpha'] * df['delta']  # 攻角与位移厚度交互
    df['U_infinity_delta'] = df['U_infinity'] * df['delta']  # 速度与位移厚度交互
    
    # 创建比值特征
    df['U_infinity_over_c'] = df['U_infinity'] / (df['c'] + 1e-8)  # 避免除零
    df['f_over_U_infinity'] = df['f'] / (df['U_infinity'] + 1e-8)  # 频率/速度，与波长相关
    df['c_over_delta'] = df['c'] / (df['delta'] + 1e-8)  # 弦长/位移厚度，与相对厚度相关
    
    # 创建多项式特征
    df['f_squared'] = df['f'] ** 2
    df['delta_squared'] = df['delta'] ** 2
    df['alpha_squared'] = df['alpha'] ** 2
    df['U_infinity_squared'] = df['U_infinity'] ** 2
    
    # 创建对数变换特征（声压级常与对数相关）
    df['log_f'] = np.log1p(df['f'])
    df['log_delta'] = np.log1p(df['delta'] * 1000)  # 放大后取对数，避免负值
    df['log_U_infinity'] = np.log1p(df['U_infinity'])
    
    # === 新增物理意义特征 ===
    # Strouhal 数相关（无量纲频率）：f * c / U_infinity
    df['strouhal'] = df['f'] * df['c'] / (df['U_infinity'] + 1e-8)
    
    # 雷诺数相关（与 U_infinity * c 成正比）
    df['reynolds'] = df['U_infinity'] * df['c']
    
    # 攻角与弦长交互
    df['alpha_c'] = df['alpha'] * df['c']
    
    # 速度平方（动压相关）
    df['U_infinity_squared'] = df['U_infinity'] ** 2
    
    # 频率与攻角交互
    df['f_alpha'] = df['f'] * df['alpha']
    
    # 弦长与位移厚度比值平方
    df['c_over_delta_squared'] = (df['c'] / (df['delta'] + 1e-8)) ** 2
    
    # 选择所有特征列（包括新创建的）
    all_feature_cols = available_features + [
        'f_delta', 'alpha_U_infinity', 'f_c', 'alpha_delta', 'U_infinity_delta',
        'U_infinity_over_c', 'f_over_U_infinity', 'c_over_delta',

    ]
    
    # 分离目标列
    if target_col in df.columns:

    """
