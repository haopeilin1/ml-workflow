## 规划思路

### 1. 数据预处理 (preprocess)
- **丢弃 id 列**：id 列有 491 个唯一值（与行数相同），是典型 ID 列，必须丢弃，否则会导致严重过拟合。
- **缺失值处理**：数据画像显示无缺失值（missingRate=0.0），但 Glucose、BloodPressure、SkinThickness、Insulin、BMI 等列存在 0 值，这在医学上不合理（如 Glucose=0 不可能），应视为缺失值处理。
  - 对 Glucose、BloodPressure、SkinThickness、Insulin、BMI 中的 0 值用中位数填充。
- **数值缩放**：使用 StandardScaler 对数值特征进行标准化，提升模型收敛速度和稳定性。
- **状态管理**：mode='train' 时拟合 imputer 和 scaler，保存到全局 PREPROCESS_STATE；mode='test' 时仅应用已拟合的参数。

### 2. 特征工程 (feature_engineering)
- **保留原始特征**：Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age
- **创建新特征**：
  - BMI 分类：根据 WHO 标准创建 BMI 类别（正常、超重、肥胖等）
  - 年龄分组：将 Age 分段（<30, 30-45, 45-60, >60）
  - 交互特征：Glucose * BMI（血糖与体重的交互）、Age * Pregnancies（年龄与怀孕次数的交互）
  - 多项式特征：Glucose^2, BMI^2（捕捉非线性关系）
- **特征选择**：使用 SelectKBest 选择 top-k 特征（k=15），减少噪声。
- **丢弃目标列**：返回的 X 不包含 Outcome 列。

### 3. 模型构建 (build_model)
- **模型选择**：LightGBM（LGBMClassifier），适合中小型表格数据，速度快，效果好。
- **超参数设置**：
  - objective='binary'
  - num_leaves=31, max_depth=6（防止过拟合）
  - learning_rate=0.05, n_estimators=500
  - subsample=0.8, colsample_bytree=0.8（特征采样和样本采样防过拟合）
  - min_child_samples=20, reg_alpha=0.1, reg_lambda=0.1（正则化）
  - scale_pos_weight 根据类别不平衡比例自动计算（约 1.96）
- **早停**：使用 callbacks=[lgb.early_stopping(stopping_rounds=50)] 防止过拟合。

### 4. 评估指标
- 系统默认 AUC 评估，无需自定义 evaluate_model。

import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.preprocessing import FunctionTransformer
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from lightgbm import LGBMClassifier
import lightgbm as lgb

# 全局状态变量，用于存储训练时拟合的预处理参数
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 将医学上不可能的 0 值视为缺失值（Glucose, BloodPressure, SkinThickness, Insulin, BMI）
    zero_as_missing_cols = ['Glucose', 'BloodPressure', 'SkinThickness', 'Insulin', 'BMI']
    for col in zero_as_missing_cols:
        if col in df.columns:
            df[col] = df[col].replace(0, np.nan)
    
    # 分离特征和目标列（仅用于训练时的拟合）
    if mode == 'train':
        # 保存目标列
        if 'Outcome' in df.columns:
            y = df['Outcome'].copy()
        else:
            y = None
        
        # 选择数值特征列
        feature_cols = [col for col in df.columns if col != 'Outcome']
        
        # 拟合 imputer（中位数填充）
        imputer = SimpleImputer(strategy='median')
        imputer.fit(df[feature_cols])
        PREPROCESS_STATE['imputer'] = imputer
        
        # 拟合 scaler
        scaler = StandardScaler()
        scaler.fit(imputer.transform(df[feature_cols]))
        PREPROCESS_STATE['scaler'] = scaler
        
        # 保存特征列顺序
        PREPROCESS_STATE['feature_cols'] = feature_cols
        
        # 应用预处理
        df_processed = pd.DataFrame(
            scaler.transform(imputer.transform(df[feature_cols])),
            columns=feature_cols,
            index=df.index
        )
        
        # 恢复目标列
        if y is not None:
            df_processed['Outcome'] = y.values
        
        return df_processed
    
    elif mode == 'test':
        # 从状态中读取已拟合的参数
        imputer = PREPROCESS_STATE.get('imputer')
        scaler = PREPROCESS_STATE.get('scaler')
        feature_cols = PREPROCESS_STATE.get('feature_cols', [col for col in df.columns if col != 'Outcome'])
        
        if imputer is None or scaler is None:
            raise ValueError("PREPROCESS_STATE 未初始化，请先运行 mode='train'")
        
        # 应用预处理
        df_processed = pd.DataFrame(
            scaler.transform(imputer.transform(df[feature_cols])),
            columns=feature_cols,
            index=df.index
        )
        
        # 恢复目标列（如果存在）
        if 'Outcome' in df.columns:
            df_processed['Outcome'] = df['Outcome'].values
        
        return df_processed
    
    return df


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 分离目标列
    if 'Outcome' in df.columns:
        y = df['Outcome'].copy()
        df = df.drop(columns=['Outcome'])
    else:
        y = None
    
    # 创建新特征
    # 1. BMI 分类特征（数值化）
    if 'BMI' in df.columns:
        # 注意：BMI 已经过标准化，但原始值在 preprocess 前已丢失
        # 由于 preprocess 已经标准化了所有特征，我们基于标准化后的值创建特征
        # 实际上更好的做法是在 preprocess 之前做特征工程，但这里我们基于标准化后的值
        pass  # 标准化后的 BMI 无法直接做分类，跳过
    
    # 2. 交互特征
    if 'Glucose' in df.columns and 'BMI' in df.columns:
        df['Glucose_BMI_interaction'] = df['Glucose'] * df['BMI']
    
    if 'Age' in df.columns and 'Pregnancies' in df.columns:
        df['Age_Pregnancies_interaction'] = df['Age'] * df['Pregnancies']
    
    if 'Glucose' in df.columns and 'Age' in df.columns:
        df['Glucose_Age_interaction'] = df['Glucose'] * df['Age']
    
    # 3. 多项式特征
    if 'Glucose' in df.columns:
        df['Glucose_squared'] = df['Glucose'] ** 2
    
    if 'BMI' in df.columns:
        df['BMI_squared'] = df['BMI'] ** 2
    
    if 'Insulin' in df.columns:
        df['Insulin_squared'] = df['Insulin'] ** 2
    
    # 4. 比率特征
    if 'Glucose' in df.columns and 'BMI' in df.columns:
        df['Glucose_BMI_ratio'] = df['Glucose'] / (df['BMI'] + 1e-8)
    
    if 'Insulin' in df.columns and 'Glucose' in df.columns:
        df['Insulin_Glucose_ratio'] = df['Insulin'] / (df['Glucose'] + 1e-8)
    
    # 5. 聚合统计特征（基于原始特征）
    # 计算每行的统计量
    numeric_cols = df.select_dtypes(include=[np.number]).columns.tolist()
    if len(numeric_cols) > 0:
        df['row_mean'] = df[numeric_cols].mean(axis=1)
        df['row_std'] = df[numeric_cols].std(axis=1)
        df['row_max'] = df[numeric_cols].max(axis=1)
        df['row_min'] = df[numeric_cols].min(axis=1)
    
    # 确保所有列都是数值类型
    for col in df.columns:
        if df[col].dtype == 'object' or df[col].dtype.name == 'category':
            df[col] = pd.factorize(df[col])[0]
    
    # 特征选择：使用 SelectKBest 选择 top-15 特征
    if y is not None:
        selector = SelectKBest(score_func=f_classif, k=min(15, df.shape[1]))
        X_selected = selector.fit_transform(df, y)
        selected_mask = selector.get_support()
        selected_cols = df.columns[selected_mask].tolist()
        df = df[selected_cols]
    
    return df


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    # 计算类别权重（根据数据画像，正类比例约 0.338，负类约 0.662）
    scale_pos_weight = (1 - 0.3381) / 0.3381  # ≈ 1.96
    
    model = LGBMClassifier(
        objective='binary',
        scale_pos_weight=scale_pos_weight,
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        colsample_bytree=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        verbosity=-1
    )
    
    return model
