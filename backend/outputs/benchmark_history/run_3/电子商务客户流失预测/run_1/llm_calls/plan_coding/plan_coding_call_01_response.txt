## 规划思路

### 1. 数据预处理 (`preprocess`)

**目标列处理**：
- 目标列 `Churn` 是字符串类型（'Yes'/'No'），需要编码为数值（1/0）
- 在 `mode='train'` 时拟合 LabelEncoder，保存到全局状态
- 在 `mode='test'` 时应用已保存的编码器

**id列处理**：
- `id` 列有 475355 个唯一值（与行数相同），是典型的ID列，必须丢弃

**StreamingTV/StreamingMovies 处理**：
- 数据画像显示它们是 categorical/str 类型，但名称看起来像数值
- 根据检查清单，需要用 `pd.to_numeric(..., errors='coerce')` 强制转换
- 但样本值显示它们是 'Yes'/'No'/'No internet service' 等字符串，转换后会全部变成 NaN
- 所以实际上它们就是类别特征，应该用 OneHotEncoder 编码，而不是数值转换
- 检查清单的要求可能是个误导，但为了安全，我会尝试转换，如果失败则保留为类别

**类别特征编码**：
- 使用 `ColumnTransformer` + `OneHotEncoder` 对类别特征编码
- 数值特征使用 `StandardScaler` 标准化
- 在 `mode='train'` 时拟合预处理器，保存到 `PREPROCESS_STATE`
- 在 `mode='test'` 时应用已保存的预处理器

**缺失值处理**：
- 数据画像显示所有列缺失率为0，但为了鲁棒性，添加 SimpleImputer

### 2. 特征工程 (`feature_engineering`)

**基础特征**：
- 保留所有原始特征（经过预处理后的）

**新特征创建**：
- `tenure` 与 `MonthlyCharges` 的交互：`tenure * MonthlyCharges`（总消费的近似）
- `tenure` 的分箱：短期（1-12）、中期（13-48）、长期（49-72）
- 服务数量聚合：计算用户订阅的服务总数（OnlineSecurity, OnlineBackup, DeviceProtection, TechSupport, StreamingTV, StreamingMovies 中 'Yes' 的数量）
- 是否同时有电话服务和互联网服务

**特征选择**：
- 丢弃 `id` 列
- 确保所有列都是数值类型

### 3. 模型构建 (`build_model`)

**模型选择**：
- 使用 LightGBM（LGBMClassifier），适合大规模数据，速度快，效果好
- 二分类任务，评估指标 AUC-ROC

**超参数设置**：
- `objective='binary'`
- `num_leaves=31`（默认）
- `max_depth=6`（防止过拟合）
- `learning_rate=0.05`
- `n_estimators=500`
- `subsample=0.8`
- `min_child_samples=20`
- `scale_pos_weight`：根据类别不平衡比例计算
- `random_state=42`

**早停**：
- 使用 `callbacks=[lgb.early_stopping(stopping_rounds=50)]`
- 使用 `eval_set=[(X_val, y_val)]`

### 4. 状态管理

- `PREPROCESS_STATE`：存储 LabelEncoder（目标列）和 ColumnTransformer（特征预处理）
- `mode='train'`：拟合并保存
- `mode='test'`：应用已保存的

import pandas as pd
import numpy as np
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler, LabelEncoder
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from lightgbm import LGBMClassifier
import lightgbm as lgb

# 全局状态变量
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 1. 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 2. 处理目标列 Churn（如果存在）
    if 'Churn' in df.columns:
        if mode == 'train':
            le = LabelEncoder()
            df['Churn'] = le.fit_transform(df['Churn'])
            PREPROCESS_STATE['churn_encoder'] = le
        else:
            le = PREPROCESS_STATE.get('churn_encoder')
            if le:
                df['Churn'] = le.transform(df['Churn'])
    
    # 3. 处理 StreamingTV 和 StreamingMovies（尝试数值转换，失败则保留为类别）
    for col in ['StreamingTV', 'StreamingMovies']:
        if col in df.columns:
            # 尝试转换为数值
            numeric_col = pd.to_numeric(df[col], errors='coerce')
            # 如果大部分是 NaN，说明是类别特征，保留原样
            if numeric_col.isna().sum() > 0.5 * len(df):
                # 保留为类别特征，不做转换
                pass
            else:
                df[col] = numeric_col
    
    # 4. 定义类别特征和数值特征
    cat_cols = ['gender', 'Partner', 'Dependents', 'PhoneService', 'MultipleLines',
                'InternetService', 'OnlineSecurity', 'OnlineBackup', 'DeviceProtection',
                'TechSupport', 'StreamingTV', 'StreamingMovies', 'Contract',
                'PaperlessBilling', 'PaymentMethod']
    
    # 只保留实际存在的列
    cat_cols = [c for c in cat_cols if c in df.columns]
    
    # 数值特征（排除目标列和类别列）
    exclude_cols = set(cat_cols + ['Churn'])
    num_cols = [c for c in df.columns if c not in exclude_cols and df[c].dtype in ['int64', 'float64']]
    
    # 5. 构建预处理器
    if mode == 'train':
        preprocessor = ColumnTransformer([
            ('cat', Pipeline([
                ('imputer', SimpleImputer(strategy='most_frequent')),
                ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
            ]), cat_cols),
            ('num', Pipeline([
                ('imputer', SimpleImputer(strategy='median')),
                ('scaler', StandardScaler())
            ]), num_cols)
        ], remainder='passthrough')
        
        # 拟合预处理器
        # 注意：这里只拟合特征部分，不包含目标列
        X = df.drop(columns=['Churn'], errors='ignore')
        preprocessor.fit(X)
        PREPROCESS_STATE['preprocessor'] = preprocessor
        PREPROCESS_STATE['cat_cols'] = cat_cols
        PREPROCESS_STATE['num_cols'] = num_cols
    else:
        preprocessor = PREPROCESS_STATE.get('preprocessor')
        if preprocessor is None:
            raise ValueError("PREPROCESS_STATE 中没有预处理器，请先运行 mode='train'")
    
    return df

def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 分离特征和目标
    y = None
    if 'Churn' in df.columns:
        y = df['Churn']
        df = df.drop(columns=['Churn'])
    
    # 应用预处理器
    preprocessor = PREPROCESS_STATE.get('preprocessor')
    if preprocessor is None:
        raise ValueError("PREPROCESS_STATE 中没有预处理器")
    
    X_processed = preprocessor.transform(df)
    
    # 获取特征名称
    cat_cols = PREPROCESS_STATE.get('cat_cols', [])
    num_cols = PREPROCESS_STATE.get('num_cols', [])
    
    # 获取 OneHotEncoder 的特征名称
    ohe = preprocessor.named_transformers_['cat'].named_steps['encoder']
    cat_feature_names = []
    for i, col in enumerate(cat_cols):
        if col in ohe.categories_:
            categories = ohe.categories_[i]
            cat_feature_names.extend([f"{col}_{cat}" for cat in categories])
    
    # 构建完整的特征名称列表
    feature_names = cat_feature_names + num_cols
    
    # 转换为 DataFrame
    X = pd.DataFrame(X_processed, columns=feature_names)
    
    # 创建新特征
    # 1. tenure 的分箱（如果 tenure 存在）
    if 'tenure' in num_cols:
        tenure_idx = num_cols.index('tenure')
        tenure_col = X.iloc[:, len(cat_feature_names) + tenure_idx]
        X['tenure_group'] = pd.cut(tenure_col, bins=[0, 12, 48, 72], labels=[0, 1, 2]).astype(int)
    
    # 2. 服务数量（如果相关列存在）
    service_cols = ['OnlineSecurity_Yes', 'OnlineBackup_Yes', 'DeviceProtection_Yes',
                    'TechSupport_Yes', 'StreamingTV_Yes', 'StreamingMovies_Yes']
    existing_service_cols = [c for c in service_cols if c in X.columns]
    if existing_service_cols:
        X['num_services'] = X[existing_service_cols].sum(axis=1)
    
    # 3. 是否有互联网服务
    if 'InternetService_Fiber optic' in X.columns or 'InternetService_DSL' in X.columns:
        X['has_internet'] = ((X.get('InternetService_Fiber optic', 0) == 1) | 
                             (X.get('InternetService_DSL', 0) == 1)).astype(int)
    
    # 4. tenure 与 MonthlyCharges 的交互
    if 'tenure' in num_cols and 'MonthlyCharges' in num_cols:
        tenure_idx = num_cols.index('tenure')
        monthly_idx = num_cols.index('MonthlyCharges')
        X['tenure_x_monthly'] = (X.iloc[:, len(cat_feature_names) + tenure_idx] * 
                                 X.iloc[:, len(cat_feature_names) + monthly_idx])
    
    # 确保所有列都是数值类型
    for col in X.columns:
        if X[col].dtype not in ['int64', 'float64']:
            X[col] = pd.to_numeric(X[col], errors='coerce').fillna(0)
    
    # 如果之前分离了目标列，重新合并（用于后续训练）
    if y is not None:
        X['Churn'] = y.values
    
    return X

def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    # 计算类别权重（从数据中获取）
    # 注意：这里只是默认值，实际会在训练时根据数据调整
    model = LGBMClassifier(
        objective='binary',
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        min_child_samples=20,
        random_state=42,
        verbose=-1  # 减少输出
    )
    
    return model
