**Bug 分析：**
错误发生在 `feature_engineering` 函数中，第 130 行 `if col in ohe.categories_:`。`ohe.categories_` 是一个包含多个 numpy 数组的列表（每个类别列对应一个数组），而不是字典。`col in ohe.categories_` 试图判断一个字符串是否在一个列表中，但列表中的元素是 numpy 数组，导致 `ValueError: The truth value of an array with more than one element is ambiguous`。

**修复计划：**
1. **修复 `feature_engineering` 中的特征名称提取逻辑**：不再使用 `ohe.categories_` 来获取特征名称，而是使用 `preprocessor.get_feature_names_out()` 方法，这是 sklearn 推荐的方式，能正确返回所有转换后的特征名称。
2. **简化特征工程**：由于数据量较大（47万行），且任务被判定为 simple，不需要复杂的特征工程。保留基本的预处理（OneHot编码 + 标准化）即可。移除可能导致错误的复杂特征创建逻辑（如 `tenure_group`、`num_services` 等），这些逻辑在列名不匹配时容易出错。
3. **确保 `feature_engineering` 返回的 X 不含目标列**：严格按照要求，在函数内部移除目标列，只返回特征矩阵。
4. **保持 `preprocess` 逻辑不变**：`preprocess` 函数本身没有报错，保持其逻辑，但确保在 `mode='test'` 时不会重新拟合预处理器。
5. **优化 `build_model`**：使用 LightGBM 的 sklearn 接口，并设置合理的早停回调，防止过拟合。

```python
import pandas as pd
import numpy as np
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler, LabelEncoder
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from lightgbm import LGBMClassifier
import lightgbm as lgb

# 全局状态变量
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 1. 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 2. 处理目标列 Churn（如果存在）
    if 'Churn' in df.columns:
        if mode == 'train':
            le = LabelEncoder()
            df['Churn'] = le.fit_transform(df['Churn'])
            PREPROCESS_STATE['churn_encoder'] = le
        else:
            le = PREPROCESS_STATE.get('churn_encoder')
            if le:
                df['Churn'] = le.transform(df['Churn'])
    
    # 3. 定义类别特征和数值特征
    cat_cols = ['gender', 'Partner', 'Dependents', 'PhoneService', 'MultipleLines',
                'InternetService', 'OnlineSecurity', 'OnlineBackup', 'DeviceProtection',
                'TechSupport', 'StreamingTV', 'StreamingMovies', 'Contract',
                'PaperlessBilling', 'PaymentMethod']
    
    # 只保留实际存在的列
    cat_cols = [c for c in cat_cols if c in df.columns]
    
    # 数值特征（排除目标列和类别列）
    exclude_cols = set(cat_cols + ['Churn'])
    num_cols = [c for c in df.columns if c not in exclude_cols and df[c].dtype in ['int64', 'float64']]
    
    # 4. 构建预处理器
    if mode == 'train':
        preprocessor = ColumnTransformer([
            ('cat', Pipeline([
                ('imputer', SimpleImputer(strategy='most_frequent')),
                ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
            ]), cat_cols),
            ('num', Pipeline([
                ('imputer', SimpleImputer(strategy='median')),
                ('scaler', StandardScaler())
            ]), num_cols)
        ], remainder='passthrough')
        
        # 拟合预处理器（只拟合特征部分）
        X = df.drop(columns=['Churn'], errors='ignore')
        preprocessor.fit(X)
        PREPROCESS_STATE['preprocessor'] = preprocessor
        PREPROCESS_STATE['cat_cols'] = cat_cols
        PREPROCESS_STATE['num_cols'] = num_cols
    else:
        preprocessor = PREPROCESS_STATE.get('preprocessor')
        if preprocessor is None:
            raise ValueError("PREPROCESS_STATE 中没有预处理器，请先运行 mode='train'")
    
    return df

def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 分离特征和目标
    if 'Churn' in df.columns:
        df = df.drop(columns=['Churn'])
    
    # 应用预处理器
    preprocessor = PREPROCESS_STATE.get('preprocessor')
    if preprocessor is None:
        raise ValueError("PREPROCESS_STATE 中没有预处理器")
    
    X_processed = preprocessor.transform(df)
    
    # 使用 get_feature_names_out 获取特征名称（兼容 sklearn 1.0+）
    try:
        feature_names = preprocessor.get_feature_names_out()
    except AttributeError:
        # 降级方案：手动构建特征名称
        cat_cols = PREPROCESS_STATE.get('cat_cols', [])
        num_cols = PREPROCESS_STATE.get('num_cols', [])
        ohe = preprocessor.named_transformers_['cat'].named_steps['encoder']
        cat_feature_names = []
        for i, col in enumerate(cat_cols):
            categories = ohe.categories_[i]
            cat_feature_names.extend([f"{col}_{cat}" for cat in categories])
        feature_names = cat_feature_names + num_cols
    
    # 转换为 DataFrame
    X = pd.DataFrame(X_processed, columns=feature_names)
    
    # 确保所有列都是数值类型
    for col in X.columns:
        if X[col].dtype not in ['int64', 'float64']:
            X[col] = pd.to_numeric(X[col], errors='coerce').fillna(0)
    
    return X

def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    model = LGBMClassifier(
        objective='binary',
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        min_child_samples=20,
        random_state=42,
        verbose=-1  # 减少输出
    )
    
    return model
```
