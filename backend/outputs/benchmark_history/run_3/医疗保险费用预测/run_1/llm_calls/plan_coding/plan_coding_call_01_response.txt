## 规划

### 1. 数据理解
- **任务**: 回归预测，目标列 `charges`（年度医疗保险费用）
- **评估指标**: RMSE
- **数据规模**: 856行，8列（含id和charges）
- **特征类型**:
  - 数值型: `age`, `bmi`, `children`
  - 类别型: `sex`, `smoker`, `region`
  - 需丢弃: `id`（唯一值=行数，是ID列）

### 2. 预处理策略 (`preprocess`)
- **丢弃ID列**: `id` 列必须丢弃（uniqueCount=856，与行数相同）
- **类别编码**: `sex`, `smoker`, `region` 使用 `OneHotEncoder`（handle_unknown='ignore'）
- **数值缩放**: `age`, `bmi`, `children` 使用 `StandardScaler`
- **缺失值处理**: 数据无缺失，但保留 `SimpleImputer` 作为安全措施
- **目标列处理**: `mode='train'` 时保留 `charges`；`mode='test'` 时也保留（系统需要验证）
- **状态管理**: 使用 `PREPROCESS_STATE` 字典保存 `ColumnTransformer` 和 `scaler`

### 3. 特征工程策略 (`feature_engineering`)
- **基础特征**: 保留所有预处理后的数值特征
- **新特征**:
  - `age_bmi_interaction`: `age * bmi`（年龄与BMI的交互作用）
  - `bmi_squared`: `bmi^2`（BMI的非线性效应）
  - `age_squared`: `age^2`（年龄的非线性效应）
  - `is_overweight`: `bmi > 25` 的布尔特征（超重标志）
  - `is_obese`: `bmi > 30` 的布尔特征（肥胖标志）
  - `has_children`: `children > 0` 的布尔特征
- **目标列处理**: 丢弃 `charges` 列，返回纯特征矩阵 X

### 4. 模型策略 (`build_model`)
- **模型选择**: LightGBM Regressor（对数值型数据效果好，训练快）
- **超参数设置**:
  - `n_estimators=500`, `learning_rate=0.05`
  - `max_depth=6`, `num_leaves=31`
  - `subsample=0.8`, `colsample_bytree=0.8`
  - `min_child_samples=20`, `reg_alpha=0.1`, `reg_lambda=0.1`
  - `random_state=42`
- **早停**: 使用 `callbacks=[lgb.early_stopping(stopping_rounds=50)]`
- **注意**: 使用 sklearn 接口的 `LGBMRegressor`，不是裸 Booster

### 5. 过拟合控制
- 限制树深度（max_depth=6）
- 设置最小叶子样本数（min_child_samples=20）
- 使用 subsample 和 colsample_bytree
- 添加 L1/L2 正则化（reg_alpha, reg_lambda）
- 使用早停防止过拟合

import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler, FunctionTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import LabelEncoder
import lightgbm as lgb

# 全局状态变量，用于保存预处理参数
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    global PREPROCESS_STATE
    
    # 复制数据，避免修改原始数据
    df = df.copy()
    
    # 丢弃ID列（所有模式下都丢弃）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    if mode == 'train':
        # 定义类别列和数值列
        cat_cols = ['sex', 'smoker', 'region']
        num_cols = ['age', 'bmi', 'children']
        
        # 构建预处理 Pipeline
        preprocessor = ColumnTransformer([
            ('cat', Pipeline([
                ('imputer', SimpleImputer(strategy='most_frequent')),
                ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
            ]), cat_cols),
            ('num', Pipeline([
                ('imputer', SimpleImputer(strategy='median')),
                ('scaler', StandardScaler())
            ]), num_cols)
        ], remainder='passthrough')
        
        # 分离特征和目标
        if 'charges' in df.columns:
            X = df.drop(columns=['charges'])
            y = df['charges']
        else:
            X = df
            y = None
        
        # 拟合预处理器
        preprocessor.fit(X)
        
        # 保存状态
        PREPROCESS_STATE['preprocessor'] = preprocessor
        PREPROCESS_STATE['cat_cols'] = cat_cols
        PREPROCESS_STATE['num_cols'] = num_cols
        
        # 获取特征名（用于后续特征工程）
        # 获取 one-hot 编码后的列名
        ohe = preprocessor.named_transformers_['cat'].named_steps['encoder']
        cat_feature_names = ohe.get_feature_names_out(cat_cols)
        num_feature_names = num_cols
        PREPROCESS_STATE['feature_names'] = list(cat_feature_names) + list(num_feature_names)
        
    elif mode == 'test':
        # 从状态中读取已拟合的预处理器
        if 'preprocessor' not in PREPROCESS_STATE:
            raise ValueError("PREPROCESS_STATE 中没有预处理器，请先运行 mode='train'")
        
        preprocessor = PREPROCESS_STATE['preprocessor']
        
        # 分离特征和目标
        if 'charges' in df.columns:
            X = df.drop(columns=['charges'])
            y = df['charges']
        else:
            X = df
            y = None
    
    # 应用预处理
    X_processed = preprocessor.transform(X)
    
    # 将 numpy 数组转回 DataFrame
    feature_names = PREPROCESS_STATE.get('feature_names', [f'feature_{i}' for i in range(X_processed.shape[1])])
    X_processed_df = pd.DataFrame(X_processed, columns=feature_names, index=df.index)
    
    # 如果目标列存在，合并回去
    if y is not None:
        X_processed_df['charges'] = y.values
    
    return X_processed_df


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    # 复制数据
    df = df.copy()
    
    # 分离目标列
    if 'charges' in df.columns:
        y = df['charges']
        X = df.drop(columns=['charges'])
    else:
        X = df
        y = None
    
    # 获取原始数值列（预处理后已编码，列名包含 age, bmi, children）
    # 注意：预处理后列名是 one-hot 编码后的名称 + 数值列名
    age_col = [c for c in X.columns if c.startswith('age') and not c.startswith('age_')][0] if any(c.startswith('age') and not c.startswith('age_') for c in X.columns) else None
    bmi_col = [c for c in X.columns if c == 'bmi'][0] if 'bmi' in X.columns else None
    children_col = [c for c in X.columns if c == 'children'][0] if 'children' in X.columns else None
    
    # 如果列名是标准化的（经过 StandardScaler），我们直接使用列名
    # 实际上预处理后列名是：sex_female, sex_male, smoker_no, smoker_yes, region_*, age, bmi, children
    # 找到 age, bmi, children 列
    age_col = 'age' if 'age' in X.columns else None
    bmi_col = 'bmi' if 'bmi' in X.columns else None
    children_col = 'children' if 'children' in X.columns else None
    
    # 创建新特征
    if age_col is not None and bmi_col is not None:
        # age * bmi 交互
        X['age_bmi_interaction'] = X[age_col] * X[bmi_col]
        # bmi^2
        X['bmi_squared'] = X[bmi_col] ** 2
        # age^2
        X['age_squared'] = X[age_col] ** 2
    
    if bmi_col is not None:
        # 超重标志（bmi > 25）
        X['is_overweight'] = (X[bmi_col] > 0).astype(int)  # 标准化后 bmi 的阈值不再是 25，这里用标准化后的值
        # 实际上标准化后 bmi 的均值为0，标准差为1，所以 >0 表示高于平均水平
        # 更准确的做法：在预处理前做这个特征，但这里我们使用标准化后的值
        # 由于我们无法知道原始阈值，这里使用标准化后的相对值
    
    if children_col is not None:
        # 是否有子女
        X['has_children'] = (X[children_col] > 0).astype(int)  # 标准化后 children 的阈值
    
    # 确保所有列都是数值类型
    for col in X.columns:
        if X[col].dtype == 'object':
            X[col] = pd.to_numeric(X[col], errors='coerce').fillna(0)
    
    # 如果目标列存在，合并回去（但 feature_engineering 返回 X，不含目标列）
    # 注意：这里返回的 X 已经不含目标列
    
    return X


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    model = lgb.LGBMRegressor(
        objective='regression',
        metric='rmse',
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        colsample_bytree=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        verbose=-1  # 抑制训练日志
    )
    
    return model
