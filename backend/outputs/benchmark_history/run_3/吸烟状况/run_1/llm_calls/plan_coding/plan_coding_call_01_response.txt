## 规划思路

### 1. 数据分析
- **任务**: 二分类（预测吸烟状态），评估指标为 ROC-AUC
- **数据**: 12000行，23个特征 + 1个目标列 `smoking`
- **类别平衡**: 目标列 `smoking` 的均值为 0.3655，说明正样本约36.6%，有一定不平衡性
- **缺失值**: 所有列缺失率为0，无需填充
- **特征类型**: 全部为数值型（float64），无类别型字符串列
- **ID列**: `id` 列有12000个唯一值，必须丢弃

### 2. 预处理策略（preprocess）
- 丢弃 `id` 列（防止过拟合）
- 清洗列名：将特殊字符替换为下划线（`re.sub('[^\\w]', '_', col)`）
- 所有特征均为数值型，无需编码
- 数值特征进行标准化（StandardScaler），在训练集上拟合，测试集上转换
- 保留目标列 `smoking`

### 3. 特征工程策略（feature_engineering）
- 输入已包含预处理后的数据（含目标列）
- 丢弃目标列 `smoking`
- 创建有意义的交叉特征：
  - BMI = weight(kg) / (height(m))^2
  - 血压差 = systolic - relaxation
  - 血脂比：triglyceride / HDL
  - 肝功比：AST/ALT
  - 平均视力 = (eyesight_left + eyesight_right) / 2
- 对偏态分布的特征做对数变换（triglyceride, Gtp, ALT, fasting blood sugar）
- 所有特征均为数值型

### 4. 模型策略（build_model）
- 使用 LightGBM（LGBMClassifier），sklearn接口
- 设置正则化参数防止过拟合：
  - max_depth=6, num_leaves=31
  - subsample=0.8, colsample_bytree=0.8
  - min_child_samples=20
  - learning_rate=0.05, n_estimators=500
- 使用 scale_pos_weight 处理类别不平衡（正样本比例约36.6%）
- 使用 early_stopping（callbacks方式）防止过拟合

### 5. 关键注意事项
- 列名清洗：`height(cm)` → `height_cm_`，需用正则替换
- 测试集无目标列，preprocess中需处理
- 使用 StandardScaler 在训练集拟合，保存状态

import re

# 全局状态变量

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 1. 丢弃 id 列
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 2. 清洗列名：特殊字符替换为下划线
    df.columns = [re.sub(r'[^\w]', '_', str(c)) for c in df.columns]
    
    # 3. 分离特征和目标列
    target_col = 'smoking'
    if target_col in df.columns:
        y = df[target_col].copy()
        X = df.drop(columns=[target_col])
    else:
        y = None
        X = df.copy()
    
    # 4. 数值特征标准化
    num_cols = X.columns.tolist()
    
    if mode == 'train':
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        PREPROCESS_STATE['scaler'] = scaler
        PREPROCESS_STATE['num_cols'] = num_cols
    else:
        scaler = PREPROCESS_STATE.get('scaler')
        if scaler is None:
            raise ValueError("PREPROCESS_STATE 中未找到 scaler，请先运行 train 模式")
        X_scaled = scaler.transform(X)
    
    # 5. 重新构建 DataFrame
    X_scaled_df = pd.DataFrame(X_scaled, columns=num_cols, index=df.index)
    
    if y is not None:
        X_scaled_df[target_col] = y.values
    
    return X_scaled_df


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 丢弃目标列
    target_col = 'smoking'
    if target_col in df.columns:
        df = df.drop(columns=[target_col])
    
    # 创建新特征
    # BMI
    if 'weight_kg_' in df.columns and 'height_cm_' in df.columns:
        df['bmi'] = df['weight_kg_'] / ((df['height_cm_'] / 100) ** 2)
    
    # 血压差
    if 'systolic' in df.columns and 'relaxation' in df.columns:
        df['blood_pressure_diff'] = df['systolic'] - df['relaxation']
    
    # 血脂比
    if 'triglyceride' in df.columns and 'HDL' in df.columns:
        df['triglyceride_hdl_ratio'] = df['triglyceride'] / (df['HDL'] + 1e-6)
    
    # 肝功比
    if 'AST' in df.columns and 'ALT' in df.columns:
        df['ast_alt_ratio'] = df['AST'] / (df['ALT'] + 1e-6)
    
    # 平均视力
    if 'eyesight_left_' in df.columns and 'eyesight_right_' in df.columns:
        df['avg_eyesight'] = (df['eyesight_left_'] + df['eyesight_right_']) / 2
    
    # 对偏态特征做对数变换（加1避免log0）
    skewed_cols = ['triglyceride', 'Gtp', 'ALT', 'fasting_blood_sugar']
    for col in skewed_cols:
        if col in df.columns:
            # 确保非负
            min_val = df[col].min()
            shift = 0 if min_val > 0 else abs(min_val) + 1
            df[f'log_{col}'] = np.log1p(df[col] + shift)
    
    # 确保所有列都是数值类型
    for col in df.columns:
        if df[col].dtype == 'object':
            df[col] = pd.to_numeric(df[col], errors='coerce')
    
    # 填充可能出现的NaN（由除零等引起）
    df = df.fillna(0)
    
    return df


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    # 计算类别权重（正样本比例约36.6%）
    scale_pos_weight = (1 - 0.3655) / 0.3655  # ≈ 1.735
    
    model = LGBMClassifier(
        objective='binary',
        scale_pos_weight=scale_pos_weight,
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        colsample_bytree=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        verbosity=-1
    )
    
    return model
