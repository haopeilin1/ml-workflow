根据错误分析，历史代码中出现了 `encoder` 未定义的错误，说明之前的代码在 `preprocess` 函数外部使用了 `encoder` 变量。我需要重新设计完整的三个函数，确保所有编码器都在 `preprocess` 函数内部定义和使用。

**修复策略：**

1. **preprocess 函数**：
   - 使用 `PREPROCESS_STATE` 全局变量存储已拟合的编码器和缩放器
   - 对类别特征列使用 `OneHotEncoder` 编码
   - 对数值特征列使用 `StandardScaler` 缩放
   - 丢弃 ID 类列：`product_price`, `discount_percent`, `product_rating`, `past_return_rate`, `delivery_delay_days`, `session_length_minutes`, `order_id`
   - 保留目标列 `returned`

2. **feature_engineering 函数**：
   - 输入已预处理的数据（仍含目标列）
   - 丢弃目标列 `returned`
   - 确保所有列都是数值类型
   - 返回特征矩阵 X

3. **build_model 函数**：
   - 使用 LightGBM 分类器，设置合理的正则化参数防止过拟合
   - 使用 `callbacks=[lgb.early_stopping(stopping_rounds=50)]` 方式（LightGBM 4.6.0 兼容）

**关键点**：
- 所有预处理逻辑都在 `preprocess` 函数内完成，包括编码器和缩放器的拟合与存储
- `feature_engineering` 只做特征选择和丢弃列操作
- 使用 `ColumnTransformer` 统一处理类别和数值特征

```python
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
import lightgbm as lgb

# 全局状态存储
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    df = df.copy()
    
    # 丢弃 ID 类列（uniqueCount ≈ rowCount）
    id_cols = ['product_price', 'discount_percent', 'product_rating', 
               'past_return_rate', 'delivery_delay_days', 'session_length_minutes', 'order_id']
    df = df.drop(columns=[col for col in id_cols if col in df.columns], errors='ignore')
    
    # 定义类别特征和数值特征
    cat_cols = ['device_type', 'product_category', 'shipping_method', 'payment_method']
    num_cols = ['customer_age', 'past_purchase_count', 'num_product_views', 'used_coupon']
    
    # 只保留存在的列
    cat_cols = [col for col in cat_cols if col in df.columns]
    num_cols = [col for col in num_cols if col in df.columns]
    
    if mode == 'train':
        # 构建预处理器
        preprocessor = ColumnTransformer([
            ('cat', Pipeline([
                ('imputer', SimpleImputer(strategy='most_frequent')),
                ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
            ]), cat_cols),
            ('num', Pipeline([
                ('imputer', SimpleImputer(strategy='median')),
                ('scaler', StandardScaler())
            ]), num_cols)
        ], remainder='passthrough')
        
        # 分离特征和目标
        target_col = 'returned'
        y = df[target_col] if target_col in df.columns else None
        X = df.drop(columns=[target_col], errors='ignore')
        
        # 拟合预处理器
        preprocessor.fit(X)
        
        # 保存状态
        PREPROCESS_STATE['preprocessor'] = preprocessor
        PREPROCESS_STATE['cat_cols'] = cat_cols
        PREPROCESS_STATE['num_cols'] = num_cols
        PREPROCESS_STATE['target_col'] = target_col
        
        # 转换数据
        X_transformed = preprocessor.transform(X)
        
        # 获取特征名称
        cat_feature_names = preprocessor.named_transformers_['cat'].named_steps['encoder'].get_feature_names_out(cat_cols)
        num_feature_names = num_cols
        all_feature_names = list(cat_feature_names) + list(num_feature_names)
        
        # 构建处理后的 DataFrame
        df_processed = pd.DataFrame(X_transformed, columns=all_feature_names)
        if y is not None:
            df_processed[target_col] = y.values
        
        PREPROCESS_STATE['feature_names'] = all_feature_names
        
    else:  # mode == 'test'
        # 从状态读取预处理器
        preprocessor = PREPROCESS_STATE['preprocessor']
        cat_cols = PREPROCESS_STATE['cat_cols']
        num_cols = PREPROCESS_STATE['num_cols']
        target_col = PREPROCESS_STATE.get('target_col', 'returned')
        feature_names = PREPROCESS_STATE.get('feature_names', [])
        
        # 分离特征和目标
        y = df[target_col] if target_col in df.columns else None
        X = df.drop(columns=[target_col], errors='ignore')
        
        # 转换数据
        X_transformed = preprocessor.transform(X)
        
        # 构建处理后的 DataFrame
        df_processed = pd.DataFrame(X_transformed, columns=feature_names)
        if y is not None:
            df_processed[target_col] = y.values
    
    return df_processed


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    df = df.copy()
    
    # 丢弃目标列
    target_col = PREPROCESS_STATE.get('target_col', 'returned')
    if target_col in df.columns:
        df = df.drop(columns=[target_col])
    
    # 确保所有列都是数值类型
    for col in df.columns:
        if df[col].dtype == 'object':
            df[col] = pd.to_numeric(df[col], errors='coerce')
    
    # 填充可能出现的 NaN
    df = df.fillna(0)
    
    return df


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    model = lgb.LGBMClassifier(
        objective='binary',
        num_leaves=31,
        max_depth=6,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        verbose=-1
    )
    
    return model
```
