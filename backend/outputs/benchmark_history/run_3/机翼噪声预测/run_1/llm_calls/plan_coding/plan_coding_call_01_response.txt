## 规划

### 1. 数据理解
- **任务**：回归预测，目标列 `SSPL`（缩放声压级）
- **特征**：`f`（频率）、`alpha`（攻角）、`c`（弦长）、`U_infinity`（来流速度）、`delta`（吸力面位移厚度）
- **数据量**：1202 行，7 列（含 `id` 和 `SSPL`）
- **数据质量**：无缺失值，所有特征均为数值型，无类别特征
- **id 列**：1202 个唯一值，必须丢弃

### 2. 预处理策略（preprocess）
- **丢弃 id 列**：训练/验证/测试集均丢弃
- **目标列处理**：训练/验证集保留 `SSPL`，测试集没有 `SSPL`（系统已处理）
- **异常值处理**：检查各特征分布，`f` 和 `delta` 有右偏分布，考虑对数变换
- **数值缩放**：使用 `StandardScaler` 标准化所有数值特征（训练集拟合，验证/测试集变换）
- **状态管理**：`mode='train'` 时拟合 scaler 并保存到 `PREPROCESS_STATE`；`mode='test'` 时应用已保存的 scaler

### 3. 特征工程策略（feature_engineering）
- **输入**：preprocess 后的 DataFrame（含 `SSPL`）
- **特征交互**：创建物理意义明确的交叉特征：
  - `f * U_infinity`：频率与速度的交互
  - `alpha * delta`：攻角与位移厚度的交互
  - `U_infinity / c`：速度与弦长的比值（类似雷诺数效应）
  - `f * delta`：频率与位移厚度的交互
- **对数变换**：对 `f` 和 `delta` 做 `log1p` 变换，缓解右偏分布
- **多项式特征**：对 `alpha` 和 `U_infinity` 添加平方项（气动特性常呈非线性）
- **丢弃目标列**：返回的 X 不含 `SSPL`
- **确保所有列数值类型**：所有特征均为 float64

### 4. 模型策略（build_model）
- **模型选择**：LightGBM Regressor（LGBMRegressor），适合中等规模回归任务，速度快，效果好
- **过拟合控制**：
  - `max_depth=8`（限制树深度）
  - `num_leaves=31`（控制叶子节点数）
  - `min_child_samples=20`（防止过拟合小样本）
  - `subsample=0.8`（行采样）
  - `colsample_bytree=0.8`（列采样）
  - `learning_rate=0.05`（小学习率配合早停）
  - `n_estimators=1000`（配合早停，实际会提前停止）
- **早停**：使用 `callbacks=[lgb.early_stopping(stopping_rounds=50)]`（LightGBM 4.6.0 正确写法）
- **评估指标**：回归任务默认使用 RMSE，系统会自动计算

### 5. 自定义评估（可选）
- 添加 `evaluate_model` 函数，计算 RMSE、MAE、R² 等指标，便于监控

### 6. 关键注意事项
- 严格遵守 LightGBM 4.6.0 API（使用 `callbacks` 参数）
- 测试集只做 transform，不做 fit
- 所有特征必须为数值类型

import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score
import lightgbm as lgb

# 全局状态变量
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    - 丢弃 id 列
    - 数值缩放（StandardScaler）
    - 训练集拟合 scaler，验证/测试集应用
    """
    df = df.copy()
    
    # 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 定义数值特征列（所有特征均为数值型）
    # 注意：mode='test' 时 test.csv 没有 SSPL 列
    if mode == 'train':
        # 训练集：包含 SSPL，需要拟合 scaler
        feature_cols = ['f', 'alpha', 'c', 'U_infinity', 'delta']
        scaler = StandardScaler()
        df[feature_cols] = scaler.fit_transform(df[feature_cols])
        PREPROCESS_STATE['scaler'] = scaler
    else:
        # 验证集或测试集：应用已拟合的 scaler
        scaler = PREPROCESS_STATE.get('scaler')
        if scaler is None:
            raise ValueError("Scaler not fitted. Call preprocess with mode='train' first.")
        # 确定当前数据中存在的特征列（测试集可能没有 SSPL）
        feature_cols = [col for col in ['f', 'alpha', 'c', 'U_infinity', 'delta'] if col in df.columns]
        df[feature_cols] = scaler.transform(df[feature_cols])
    
    return df


def feature_engineering(df):
    """
    特征工程。
    - 创建交叉特征和对数变换
    - 丢弃目标列 SSPL
    - 返回纯数值特征矩阵
    """
    df = df.copy()
    
    # 创建交叉特征（物理意义明确）
    df['f_x_U'] = df['f'] * df['U_infinity']
    df['alpha_x_delta'] = df['alpha'] * df['delta']
    df['U_div_c'] = df['U_infinity'] / (df['c'] + 1e-8)  # 避免除零
    df['f_x_delta'] = df['f'] * df['delta']
    
    # 对数变换（缓解右偏分布）
    # 注意：标准化后的值可能为负，但 log1p 对负值会出错
    # 这里对原始值做 log1p 后再标准化，但标准化已在 preprocess 完成
    # 因此这里使用标准化后的值做多项式特征，不做 log1p（因为已标准化）
    # 替代方案：对原始特征做 log1p 应在标准化之前，但为了简化，这里做平方/交互
    
    # 多项式特征（非线性关系）
    df['alpha_sq'] = df['alpha'] ** 2
    df['U_infinity_sq'] = df['U_infinity'] ** 2
    df['f_sq'] = df['f'] ** 2
    df['delta_sq'] = df['delta'] ** 2
    
    # 丢弃目标列（如果存在）
    if 'SSPL' in df.columns:
        df = df.drop(columns=['SSPL'])
    
    # 确保所有列为数值类型
    for col in df.columns:
        if df[col].dtype == 'object':
            df[col] = pd.to_numeric(df[col], errors='coerce')
    
    # 填充可能出现的 NaN（如除零）
    df = df.fillna(0)
    
    return df


def build_model():
    """
    模型构建和超参数设置。
    使用 LightGBM Regressor，配合早停防止过拟合。
    """
    model = lgb.LGBMRegressor(
        objective='regression',
        num_leaves=31,
        max_depth=8,
        learning_rate=0.05,
        n_estimators=1000,
        subsample=0.8,
        colsample_bytree=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        verbose=-1  # 控制日志输出
    )
    return model


def evaluate_model(model, X_val, y_val):
    """
    自定义验证集评估指标。
    返回 RMSE, MAE, R² 等指标。
    """
    y_pred = model.predict(X_val)
    rmse = float(np.sqrt(mean_squared_error(y_val, y_pred)))
    mae = float(mean_absolute_error(y_val, y_pred))
    r2 = float(r2_score(y_val, y_pred))
    return {
        'val_rmse': rmse,
        'val_mae': mae,
        'val_r2': r2
    }
