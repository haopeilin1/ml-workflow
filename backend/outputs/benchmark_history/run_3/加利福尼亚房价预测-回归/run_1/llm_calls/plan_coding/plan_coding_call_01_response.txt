## 规划

### 1. 数据预处理 (preprocess)
- **丢弃 id 列**：`id` 列是单调递增的标识列，uniqueCount=rowCount，必须丢弃，防止过拟合。
- **类别特征编码**：`ocean_proximity` 是低基数类别特征（5个类别），使用 `OneHotEncoder(handle_unknown='ignore')` 编码。
- **缺失值处理**：`total_bedrooms` 有 1.25% 缺失值，使用 `SimpleImputer(strategy='median')` 填充。
- **数值缩放**：对数值特征使用 `StandardScaler` 标准化，有助于树模型和线性模型收敛。
- **状态管理**：在 `mode='train'` 时拟合 `ColumnTransformer` 并保存到 `PREPROCESS_STATE`；`mode='test'` 时直接应用已保存的 transformer。
- **目标列保留**：`mode='test'` 时保留目标列 `median_house_value`（验证集需要用于评估）。

### 2. 特征工程 (feature_engineering)
- **创建比率特征**：房间数/家庭数、卧室数/房间数、人口/家庭数等比率特征，能反映密度信息。
- **创建交互特征**：经纬度组合（地理位置聚类）、收入与房龄的交互。
- **对数变换**：对偏态分布的特征（`total_rooms`, `total_bedrooms`, `population`, `households`, `median_income`）做 log1p 变换，减少长尾影响。
- **丢弃目标列**：返回的特征矩阵 X 不包含 `median_house_value`。
- **确保所有列为数值类型**：类别特征已在 preprocess 中编码为数值。

### 3. 模型构建 (build_model)
- **选择 LightGBM**：回归任务，数据量适中（16512行），LightGBM 速度快、效果好。
- **正则化参数**：
  - `max_depth=8`（限制树深度）
  - `num_leaves=31`
  - `min_child_samples=20`（防止过拟合）
  - `subsample=0.8`（行采样）
  - `colsample_bytree=0.8`（列采样）
  - `learning_rate=0.05`，`n_estimators=500`（配合早停）
- **早停**：使用 `callbacks=[lgb.early_stopping(stopping_rounds=50)]`（LightGBM 4.6.0 兼容写法）。
- **目标函数**：`objective='regression'`，`metric='rmse'`。

### 4. 整体 Pipeline 结构
- 使用 `sklearn.pipeline.Pipeline` 将预处理、特征工程、模型串联。
- 注意：特征工程中的自定义变换（如比率特征、对数变换）通过 `FunctionTransformer` 实现。
- 类别编码在 `ColumnTransformer` 中完成，确保训练/测试集列数一致。

### 5. 关键注意事项
- 禁止使用 `pd.get_dummies`，必须用 `ColumnTransformer` + `OneHotEncoder`。
- 禁止在 `mode='test'` 时拟合任何参数。
- 模型必须使用 sklearn 接口（`LGBMRegressor`），禁止裸 Booster。
- 所有特征列必须为数值类型。

```python
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder, StandardScaler, FunctionTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.base import BaseEstimator, TransformerMixin
from lightgbm import LGBMRegressor
import lightgbm as lgb

# 全局状态变量，用于存储预处理阶段拟合的参数
PREPROCESS_STATE = {}

def preprocess(df, mode='train'):
    """
    数据清洗和预处理。
    mode='train' 时拟合参数，保存到 PREPROCESS_STATE。
    mode='test' 时应用已保存的参数。
    返回处理后的 DataFrame（仍包含目标列）。
    """
    global PREPROCESS_STATE
    
    # 复制数据，避免修改原始数据
    df = df.copy()
    
    # 丢弃 id 列（如果存在）
    if 'id' in df.columns:
        df = df.drop(columns=['id'])
    
    # 分离特征和目标列
    target_col = 'median_house_value'
    if target_col in df.columns:
        y = df[target_col].copy()
        df_features = df.drop(columns=[target_col])
    else:
        y = None
        df_features = df.copy()
    
    # 定义数值列和类别列
    cat_cols = ['ocean_proximity']
    num_cols = [col for col in df_features.columns if col not in cat_cols]
    
    if mode == 'train':
        # 构建预处理 Pipeline
        preprocessor = ColumnTransformer([
            ('cat', Pipeline([
                ('imputer', SimpleImputer(strategy='most_frequent')),
                ('encoder', OneHotEncoder(handle_unknown='ignore', sparse_output=False))
            ]), cat_cols),
            ('num', Pipeline([
                ('imputer', SimpleImputer(strategy='median')),
                ('scaler', StandardScaler())
            ]), num_cols)
        ], remainder='passthrough')
        
        # 拟合预处理器
        preprocessor.fit(df_features)
        
        # 保存到全局状态
        PREPROCESS_STATE['preprocessor'] = preprocessor
        PREPROCESS_STATE['num_cols'] = num_cols
        PREPROCESS_STATE['cat_cols'] = cat_cols
        
        # 转换数据
        transformed = preprocessor.transform(df_features)
        
        # 获取特征列名
        cat_encoder = preprocessor.named_transformers_['cat'].named_steps['encoder']
        cat_feature_names = cat_encoder.get_feature_names_out(cat_cols).tolist()
        feature_names = num_cols + cat_feature_names
        
        # 转换为 DataFrame
        df_transformed = pd.DataFrame(transformed, columns=feature_names, index=df_features.index)
        
    else:  # mode == 'test'
        # 从全局状态读取预处理器
        preprocessor = PREPROCESS_STATE.get('preprocessor')
        if preprocessor is None:
            raise ValueError("PREPROCESS_STATE 中没有预处理器，请先运行 mode='train'")
        
        # 应用已拟合的预处理器
        transformed = preprocessor.transform(df_features)
        
        # 获取特征列名
        cat_encoder = preprocessor.named_transformers_['cat'].named_steps['encoder']
        cat_feature_names = cat_encoder.get_feature_names_out(PREPROCESS_STATE['cat_cols']).tolist()
        feature_names = PREPROCESS_STATE['num_cols'] + cat_feature_names
        
        # 转换为 DataFrame
        df_transformed = pd.DataFrame(transformed, columns=feature_names, index=df_features.index)
    
    # 重新添加目标列（如果存在）
    if y is not None:
        df_transformed[target_col] = y.values
    
    return df_transformed


def feature_engineering(df):
    """
    特征工程。
    返回特征矩阵 X（必须不含目标列，所有列必须是数值类型）。
    """
    # 复制数据
    df = df.copy()
    
    # 分离目标列
    target_col = 'median_house_value'
    if target_col in df.columns:
        y = df[target_col]
        df = df.drop(columns=[target_col])
    else:
        y = None
    
    # 确保所有列都是数值类型
    # 注意：类别特征已经在 preprocess 中编码为数值，这里不需要额外处理
    
    # 创建比率特征
    # 房间数/家庭数（平均每户房间数）
    if 'total_rooms' in df.columns and 'households' in df.columns:
        df['rooms_per_household'] = df['total_rooms'] / (df['households'] + 1e-5)
    
    # 卧室数/房间数（卧室占比）
    if 'total_bedrooms' in df.columns and 'total_rooms' in df.columns:
        df['bedrooms_per_room'] = df['total_bedrooms'] / (df['total_rooms'] + 1e-5)
    
    # 人口/家庭数（平均每户人口）
    if 'population' in df.columns and 'households' in df.columns:
        df['population_per_household'] = df['population'] / (df['households'] + 1e-5)
    
    # 卧室数/人口（人均卧室数）
    if 'total_bedrooms' in df.columns and 'population' in df.columns:
        df['bedrooms_per_population'] = df['total_bedrooms'] / (df['population'] + 1e-5)
    
    # 对数变换（对偏态分布的特征）
    skewed_features = ['total_rooms', 'total_bedrooms', 'population', 'households', 'median_income']
    for feat in skewed_features:
        if feat in df.columns:
            df[f'{feat}_log'] = np.log1p(df[feat])
    
    # 交互特征：收入与房龄
    if 'median_income' in df.columns and 'housing_median_age' in df.columns:
        df['income_age_interaction'] = df['median_income'] * df['housing_median_age']
    
    # 经纬度组合特征（地理位置聚类）
    if 'latitude' in df.columns and 'longitude' in df.columns:
        df['lat_lon_combined'] = df['latitude'] * df['longitude']
    
    # 确保所有列都是数值类型（int/float）
    # 理论上经过 preprocess 后所有列都是数值，但做一次安全检查
    for col in df.columns:
        if df[col].dtype == 'object':
            # 如果还有 object 列，强制转换为数值（可能包含 NaN）
            df[col] = pd.to_numeric(df[col], errors='coerce')
    
    # 填充可能出现的 NaN（除法导致的）
    df = df.fillna(0)
    
    # 返回特征矩阵
    return df


def build_model():
    """
    模型构建和超参数设置。
    返回 sklearn 兼容的模型对象（支持 fit/predict/predict_proba）。
    """
    model = LGBMRegressor(
        objective='regression',
        metric='rmse',
        num_leaves=31,
        max_depth=8,
        learning_rate=0.05,
        n_estimators=500,
        subsample=0.8,
        colsample_bytree=0.8,
        min_child_samples=20,
        reg_alpha=0.1,
        reg_lambda=0.1,
        random_state=42,
        n_jobs=-1,
        verbose=-1  # 抑制训练日志
    )
    
    return model
```
